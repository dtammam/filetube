# Lessons: the Rules

The long tail behind [`LESSONS.md`](LESSONS.md): one-line rules and their guards, under the same section
numbers. Read `LESSONS.md` (the Classes) first; come here for the section your change touches. Same

## 1. Gate, diagnosis and honesty

- **Running seats:** send each delta to the SAME instance that filed the findings (record seat ids in the plan; a cold reader is an addition, never a substitute); `git status --short` clean before spawning, since hooks test the TREE; brief by SURFACE, not glob, naming your own fear, and add the security seat on any network boundary, admin surface or file-writing POST; high-risk waves fan out one reviewer per risk dimension; subagent work gets the SAME gate, verified by machine, not by its report. (v1.41.13, v1.63-v1.65, v1.79, v1.166.4, v1.272-v1.315)
- **When seats disagree, measure:** a "redundant guard" claim is swept across every input class and the mutant run yourself (numbers off a tree another seat mutates do not reproduce); both seats can be right, resolved by DISCLOSURE or a measured keep (a comment stating the measurement, never a vacuous test); a suggestion contradicting a LOCKED decision loses unless re-litigated; a superseded approach is REVERTED fully (functions, listeners, exports, test hooks, tests). (v1.31, v1.103, v1.162-v1.187, v1.220, v1.271-v1.279)
- **Approvals bind HASHES,** and shipping stays honest: code after APPROVE is re-gated and the post-amend tip is stated to seats; a revisit trigger firing mid-gate is the next wave; a partial ship is a NAMED split disclosed in ROADMAP + tech-debt (ship-then-clean the approved hash; the data-mutating half later under the full gate, plan still ACTIVE); experiments ship default OFF with a live kill switch, a byte-identical old path, and the OFF arm tested in a fresh page session; the gate is never cut, and a one-time approved skip is no precedent. (v1.44, v1.73, v1.75, v1.86.3, v1.113-v1.115, v1.121, v1.136.1, v1.259, v1.265)
- **Every capability needs a human path to it.** Guard: click through the app before the gate, from a fresh-install zero state; a route without UI is a scope defect; ship reports list on-device probes. (v1.49, v1.50, v1.69)
- **Claims are derived, not remembered:** "shipped in vX" via `git log --diff-filter=A` + `git tag --contains`, bulk edits keep the old value ("Was: ..."); an "everything else" set is generated by the tool; a HEADLINE claim needs a COMMITTED instrument that reds when the constant reverts; a fix-chain ledger's first entry claims the ATTEMPT, only the last the win, with predictions checked against OUTPUT and blocklists widened from real escapes. (v1.125, v1.135, v1.144, v1.272, design tokens)
- **The plan's test section is a contract:** diff its "Tests:" lines against the tree before review, re-verify every promise after a pivot, give every named risk a branch and test, write deviations back into the plan. (v1.112-v1.257)
- **Plans and docs are gate targets:** plan surveys and audit tables are hypotheses (machine-enumerate, check theme/era overrides); verify doc mechanism claims against source; hunt invented stats, stale present tense, stale versions and broken GFM pipes; sweep companion docs after a removal; re-verify carried-forward claims; a completed plan is a snapshot (annotate it, update the LIVE authorities); retiring an instruction retires every CHANNEL injecting it (agent/command descriptions, session hooks); strong specs have verified anchors, scope fences and acceptance criteria in BOTH directions. (v1.30, v1.37.5-v1.41.19, v1.55, v1.67, v1.197, v1.206, design tokens)
- **Evidence before spend:** when the platform acts before page code, instrument the gap first; run the FREE falsifying variant before an infra experiment; check the platform version and the user's EXACT OS before a fragile device-API feature; bisect remotely with a visible version stamp and DISCRIMINATING error bodies (two features failing on one dependency = one cause). (v1.93, haptics, PWA audio coupling, 2026-09-24)
- **In a diagnostics wave, evidence fidelity is the product:** mutation-test formatters, log once per load (presence AND absence), nothing throws before the debug gate, a decision table before the repro, screenshot before ring buffers evict, a Settings toggle since PWAs drop `?debug=`. (v1.131, v1.136, v1.161.1)
- **Intake:** on a terse visual tweak restate ELEMENT + STATE and get a yes; confirm DEPTH and challenge the ask (is it a bug report, is "redesign" a new layout, does a library want ACCESS over browse, which axis scopes it, what already exists or syncs; an untappable control is worse than none; "make it feel like X" is a mockup arc); describe a command's REAL error path and settings (`gh pr merge --auto --squash`); mid-turn pings are unseen, so lead the next text with the answer. (v1.163, v1.206, v1.213-v1.243, Roku)
- **De-identification is verified by a LINE-JOINED whole-tree scan** (names, fragments, hints, identifiers, salts) plus a generated sweep. (v1.44.3, v1.48)
- **Ruthless honesty: failures verbatim with counts first, known gaps DISCLOSED.** Guard: hardening ships labeled as hardening; untestable wiring ships disclosed; probes WARN on partial states; never overclaim a symptom; any bypass needs a written reason; no em dashes (entities included).

## 2. Test binding: can the test actually fail?

- **Constants, boundaries and order:** a test importing the constant it checks cannot fail and `==` greens a MISSING export (literal numbers + a behaviour drive, opts asserted at the USE site, `strictEqual` + `typeof`); binding a MODEL is not binding its PARAMETERS (pin each where its effect is reached; guessed matched offsets bound EQUAL to each other); operators, clamps and constants need fixtures below, ON and PAST the boundary (over-drive a clamp, kill every previously tried constant, walk the real state machine); a sort tiebreak needs 3+ ties in an order matching NEITHER direction; a perf lock must fail its own quadratic mutant. (v1.54-v1.76, v1.163.3, v1.211-v1.272)
- **Bind the POSITIVE invariant and the SPREAD, not just an absence** (dedup keeps every genuine item; variety asserts distinct >= 2 with both-direction counters), and assert every SEEDED value, a valid 0 included (`chapterStartSec: 0`). (v1.169-v1.221)
- **Bind through the real thing:** helper + pure-core tests give ZERO wiring coverage (sweep the pure fn AND drive one test through the REAL caller; an unexported render closure gets its data path + a render-shape lock); a lock against a LITERAL or a DERIVED set binds nothing (functional bind; derived set == registry in BOTH directions); mirrors and relaxations need a DIFFERENTIAL sweep; embedded assets are byte-identical to the rebuilt on-disk asset; a variant's RENDERER IDENTITY is its own assert. (v1.63, v1.83-v1.109, v1.167-v1.208, v1.260, v1.261, v1.297)
- **Kill records:** any test or fixture edit reopens them (a rewritten binding reds against the prior tag; re-run an assertion's mutants before dropping it; a timing change re-runs the whole set); reviewer counter-examples become regression tests verbatim; never bind the unbindable (`querySelector` finds CSS-hidden nodes; comment what must change first, pin a disproof as a tripwire, never synthesize a state the product never hits). (v1.34, v1.41.6, v1.53, v1.271, v1.273, v1.296)
- **Fixture realism:** write tests act as a NON-first user (`assert(actor.id !== 1)`, a second session minted with the route family); coercion tests include `'42'` and `['x']` (type-check before coercion); fixtures come from the real mechanism (`\u` escapes, real generators, a hostile `__proto__` via `JSON.parse`); drive the mandatory USER PATH end to end (add -> type -> save) with ids from the TARGET namespace. (v1.37.5, v1.63-v1.79, v1.201)
- **Bind writes and deletes AT THE STORE** (a read filter masks write bugs; deletes count to zero; "writes zero rows" spies on the adapter during a REAL rescan), and a destructive-arm test REACHES the arm (both colliding rows live; populate-then-reap per carrier site). (v1.68-v1.78, v1.291-v1.295)
- **Doubles and bridges are part of the trust chain:** copy a fake's CONTRACT; storage mocks are argument-aware; a "never touched" spy wraps EVERY fs entry point; re-arm every fake after `_resetForTests()` with an out-of-band network tripwire in afterEach; spawning code gets a real-app BRIDGE test (real server.js, stub binaries on PATH before require, `test/integration/transcode-execution.test.js`) paired with source verification. (v1.33, v1.36, v1.56, v1.146-v1.296)
- **jsdom recipes and hangs:** a non-requirable page = JSDOM of the REAL shell (`runScripts:'dangerously'`, a public/ requestInterceptor, a fetch ROUTER never-settling for unknowns, stubbed Notification/PushManager/serviceWorker/matchMedia); a closure view = real `#view-root`, `delete require.cache`, real click/keydown; a boot-path timer hangs every jsdom boot test (close windows in after(), require common.js with NO document then attach globals, `__` hooks stand timers down); a longer BOOT await chain breaks "don't-care" stubs (sweep harnesses; scope fetch counters, never loosen). (v1.67-v1.102, v1.156-v1.161)
- **jsdom gaps:** `document.hidden` is TRUE unless `pretendToBeVisual: true` (a visibility-gated driver silently never starts); no layout (stub `getBoundingClientRect`, `scrollWidth`/`scrollHeight`); realm mismatches (`new dom.window.AbortController()`, modules read Node's `global.performance`, Node >= 21 `navigator` is getter-only, use `dom.window.document`); no canvas; synthetic clicks reach DISABLED buttons; no CSS transitions; sync dispatch pins dt ~0; a fixture missing a wired element skips it; factory default params freeze a global at require time (late-bind). (v1.68, v1.83, v1.156-v1.166, v1.233, v1.256, v1.316)
- **A hang is not a red** (v1.334: a jsdom realm running the live router keeps intervals alive - close its window in a `finally`; settle a realm's pending promises before restoring globals, or its late `.then` lands in the next realm): a harness round-breaker for spin loops, zero-rect guards in geometry math, `node --test --test-timeout=90000`; teardown in `finally` and exit cleanup in `process.on('exit')`; confirm a run COMPLETED before quoting a kill count; long runs log to a file with a Monitor on `^not ok`, the summary and a SUITE_EXIT sentinel, `tee` everything, `grep "^not ok"`, never tail. (v1.66-v1.78.1, v1.146, v1.235-v1.253)
- **Deterministic test hygiene:** `fs.mkdtempSync` paths cleaned by `test/helpers/tmp-cleanup.js` via `node --require`; read mutant failure TEXT, not counts; dynamic date offsets and env-overridable timing constants (`FILETUBE_TTS_DEFER_POLL_MS`, PROGRESS_FLUSH_MS); run a new timing/random test 20-30x, seeded, pinning bounds (a warmed LCG checked against mulberry32); quiesce timers and stub fetch in DOM tests. (v1.37, v1.65-v1.194, v1.272)
- **Test environment:** real-ffmpeg tests SKIP unless `FILETUBE_TEST_FFMPEG` points at a static ffmpeg; the suite stamps `/tmp/filetube.db` and `./filetube.db` to the branch SCHEMA_VERSION, so `rm -f` both after a cross-schema switch. (v1.194-v1.196, 2026-09-24)

## 3. Locks, censuses and instruments

- **Instruments are code:** positive controls for every parser shape, mutation tests and an attempt to FOOL it before publishing counts; self-proofs run the REAL parser and a hook's test EXECUTES the hook; an instrument that can match ITSELF excludes itself (marker words assembled from halves); a tool rewriting attributed cells needs an identity invariant. (v1.75, v1.129, v1.290, v1.291, design tokens)
- **Lock craft:** write the lock BEFORE adding pool entries; same-affordance rules need a MIRROR lock plus a DIRECT property guard; bind a scoped fix with a NEGATIVE lock on the global form (`doesNotMatch(/\n\s*#seek-bar\s*\{/)`); a new element never reuses a census-enumerated class; a SHAPE change rots every lock on the old shape (grep test/, extract with `function ${name}\([^)]*\)`, a schema bump joins the born-complete list); text sweeps get SUBSTRING locks over every served shell; write regexes directly in JS (a CDP template literal eats backslashes: `new RegExp('https?:/' + '/...')`). (v1.50, v1.68.3, v1.85-v1.167, v1.229, v1.257, v1.311.2)
- **Automated coverage ends at the device:** `test/integration/shell-smoke.test.js` boots every shell; headless WebKit cannot reproduce lock-screen audio, Media Session or rotation, so flag "unverified-on-device"; an "is-on" class is not a painted frame (sample PIXELS; `elementFromPoint` is vacuous under `pointer-events:none`; `canvas.captureStream` into the real `<video>` plays with no file). (v1.26, v1.27, v1.197.1, v1.205.1)
- **Probe fidelity:** a diagnostic that diverges from the real mechanism LIES (read constants from the DRIVER, reuse the real element); measure before fixing perf with a default-off instrument injected from ONE choke point (`sendShellHtml`), thresholds from the baseline, the undesigned mode measured too; LOOK at previews (tools/capture Playwright, inline CSS/JS). (v1.201, v1.274, v1.300, v1.301, v1.307, v1.327)
- **Headless facts:** Playwright cannot intercept Service Worker traffic (`serviceWorkers: 'block'`) and `route.continue()` follows redirects (fetch with maxRedirects:0); a `max-width` query needs the viewport meta; Chromium needs `--disable-dev-shm-usage` on a small /dev/shm, has no H.264 (VP9 webm), its ffmpeg lacks lavfi/x264/tile (ffmpeg-static); YouTube loads logged-out via CDP; Mermaid parse-checks headless with mermaid v11 + the repo jsdom. (v1.135, v1.204, v1.311.2, v1.312, v1.332)
- **Button changes are MEASURED before/after with `scripts/action-row-probe.js`:** a CSS-blind gate cannot catch overflow.
- **A comment that contains braces hides the next rule from a flat `selector{body}` scan** (a comment above `.ipod-brick` quoted `.mms-full{position:fixed}`). Guard: mask comments with same-length filler that KEEPS no braces (offsets preserved) before scanning, then edit the original at the same offsets; re-scan after any scripted rewrite. (v1.335)

## 4. SPA shell, client lifecycle and async UI state

- **Classic scripts share ONE global scope:** a duplicate top-level `const`/`let` is a SyntaxError that kills the whole second script. Guard: `shell-script-global-collisions.test.js`; deliberate duplicates are `function`/`var`. (v1.26.3)
- **TDZ brick:** a sync call above a `let` it touches, or an early return above later declarations, throws every run and the router swallows it. Guard: calls and returns BELOW every declaration they reach; a vm+DOM test runs the REAL init (`watch-init-behavioral.test.js`); timer-borne reads need a live probe. (v1.54, v1.197.1)
- **DOM lookup and mutation facts:** a `<template>` child is unreachable at init (a guard-once binder at init AND the clone site); `getElementById` returns the FIRST match and misses detached trees (container-scoped `querySelector`); `insertBefore` needs a DIRECT child (`:scope >`, re-grep anchors on a layout move); `el.textContent =` destroys child icons (a label span); SVG needs `createElementNS`. (v1.44.2-v1.255)
- **Init robustness:** never interpolate stored values into selectors (iterate and compare); a silent `.catch(()=>{})` kills every later build in the same `.then`, so a feature absent with no console error = a swallowed rejection; new render sections go LAST; pre-paint flags cannot stop the FIRST paint (unconditional classes before any storage read, outside the try; server-side injection before `express.static` with HTML `no-cache`); pop-out seams build events and timers in the owning realm (`new (window.CustomEvent || CustomEvent)`, `win.setTimeout`) and scope teardown to the registering instance (`if (pipWin === win)`), with a jsdom `close()` stub that only marks. (v1.41-v1.44.3, v1.85, v1.229-v1.257)
- **Router and URLs:** an upstream `stopPropagation` starves the delegated router, and a full reload kills the player (drive `FileTube.navigate` explicitly or make the control a SIBLING of the anchor; ask "does the handler RECEIVE it?" apart from "does it route it?"); strip a consumed marker (`?nowplaying=1`) with replaceState before anything can throw; links out of a mode-switched view carry scope params (`?browse=1`); a new reroute carries an origin marker (`&ao=1`) so the legacy path stays byte-unchanged. (v1.79, v1.103, v1.153, v1.161, v1.236)
- **Navigation state:** an in-memory sub-navigation has NO back-stack (pushViewState only on the INTERACTIVE descent, onPopState reconciles before the router's swap, in-app Back = `history.back()`, every descent enumerated); every swap owns its scroll (`history.scrollRestoration='manual'`, the REAL scroller found by measurement, restore after layout, restore side effects keyed on CALLER INTENT); a re-entry guard is not a supersession guard (cancel the prior visit's async at entry); an SPA re-init reseeds from the live player (`getCurrentMeta`), with its own reveal AND clear binding. (v1.104, v1.105, v1.160, v1.164, v1.216-v1.218)
- **Controls on persistent surfaces:** a config control lives in ONE nav-path-independent home (Settings), never bound to the first view's signal (enumerate every route to a page and every surface of a SYNCED setting); a parity-locked template gets view-only controls injected at runtime (id-guarded, re-queried, `{signal}`-bound); a control showing some state RE-DRAWS when any other surface or in-page arm changes it (the sticker's Lighting chips vs the LCD's Settings > Lighting check; unsubscribe vs subscribe modal), bound with DRIVEN listeners from each writer. (v1.186, v1.211-v1.230, v1.284, v1.314, v1.318, v1.333)
- **Timers and heals:** a stashed handle, cancel-before-rearm, cancel on re-context, a fire-time re-check, and a catch that stops a self-rescheduling loop also blocks the reschedule (`hardFailed`); a `wire()` calling its own `unwire()` strips listeners attached above it (assert NET attached state); event-driven heals need a path where NO event arrives (iOS drops orientationchange: heal on resize/pageshow/visibilitychange, idempotent + rAF-coalesced), and a surface shown on a flag is reconciled against the real DOM. (v1.166.4-v1.187.2, v1.219, v1.271, v1.277)
- **Pointer-gesture playbook:** element-bound pointer events, lazy `setPointerCapture` after ~8px, end on pointerup AND pointercancel, null the ref only if identical, reset on re-render, filter by pointerId, one-shot click-suppress, a new mode OWNS the gesture, `touch-action:none` on scrub; a document arm outlives its rows (refuse `!isConnected`; dual-arm teardown, since a mouse has no implicit capture); a drag helper closing over indexes is re-wired after every move (test two gestures; keyboard tests FOCUS the handle). (v1.34, v1.76, v1.202, v1.233-v1.242, v1.271)
- **Event and hit-testing facts:** a pointer click leaves a button focused and Space re-clicks it (capture-phase blur, `if (!e.detail) return;`, never preventDefault); `pointer-events:none` nodes are never `e.target`; a swallowing hit test respects z-ORDER; preventDefault on mousedown does not stop the click; an expanded `::after` zone can shadow a neighbour (measure in grid AND list). (v1.43.1-v1.189.1)
- **Overlays:** backdrop dismiss needs pointerdown AND click on the backdrop (`bindBackdropDismiss`, #223) and the opener stops propagation; a transient overlay's handle is assigned BEFORE append and its toggle checks ATTACHMENT (`h && h.parentNode`); a visibility-keyed consumer enumerates every path that HIDES it (`.modal-backdrop:not(.modal-closing)`); a settle-once modal runs onPick synchronously so `navigator.share` keeps its gesture. (v1.49-v1.110, v1.257, v1.289)
- **Async guards:** a guard that can never fire is dead (ask what is TRUE when it runs, given its only caller; bind with a FETCH-COUNT test); async-settled guards are EVENT-bounded, never wall-clock; an out-of-band caller makes every await in a render observable (bind "acts on what is ON SCREEN"); view continuations carry the view's AbortSignal (`if (signal.aborted) return`). (v1.45-v1.52, v1.104, v1.273)
- **Async UI policy:** never gate core controls on an ancillary fetch, and capability affordances stay HIDDEN until confirmed; a "cover during async load" survives the SYNC epilogue (a pending flag cleared on every exit, reset in destroy()/init()); optimistic consumers never act IRREVERSIBLY (a toggle flips after `res.ok` and persists onto the in-memory entry); page-lifetime dismiss sets prune when the item is active again; prefer stateless re-evaluated rules at timing-uncertain seams. (v1.40-v1.81, v1.243, v1.244, v1.283)
- **Rendering:** re-find nodes by selector + geometry or INDEX (identity is blind to innerHTML rebuilds); paint once at the final position (quiet-debounce + a skeleton gate over every flavour + a hard cap; validate restored layout against CURRENT geometry; rAF with a sync fallback); reveal media only on CONFIRMED load (img `load`, `error` fallback, `src` LAST; video on `playing`; onerror marks nofile, never re-probes). (v1.93.2-v1.225)
- **Controls tell the truth:** errors route through the shared visible helper (`setFieldError`); shown Prev/Next stay enabled; a toggle over a PARTIAL projection is all-or-nothing with ONE predicate (a `return true` mutant reds every surface); an option filter never drops the subject's own value; settings split BLANK from 0 and bound stored values on read; keyboard steps CLAMP; a capped list WINDOWS around the focus index; reset a cached idx to -1 on edit/load; `el && a === el`, widening sibling predicates together. (v1.41.11-v1.242)
- **Moving or removing controls:** relocate battle-won id-keyed controls; a replacement that becomes THE sole trigger exists in every state the old covered; grep every classList/style/setAttribute site; CSS `display:none` does not reach a JS proxy. (v1.112, v1.152)

## 5. Media playback, queue and chapters

- **Queue and play semantics.** Classify every play call site as SELECT vs NAV (auto-advance via onNext is NAV; only nav passes `{keepPosition:true}`), and refresh anything gated on `currentId` AFTER load() sets it. An early-return fast path (adopt, same-item re-entry) still refreshes every context field. Queue context steps the server's displayed order VERBATIM (`items.map(id)`), each surface gets its own `src` in the browse-context pair, and no branch keys on a GLOBAL setting a scoped view also satisfies (scope-leak test). A tap plays the TAPPED item from its start; resume offsets belong to "continue" only, and a suppressed prompt takes no action. A synthetic id (`::c`) is normalized at EVERY comparison seam through one helper (`queuePointerMatchesPlaying`); a route keyed on a non-unique discriminator also checks `kind === 'media'`. (v1.40, v1.44.1, v1.47, v1.88, v1.97, v1.104, v1.106, v1.222, v1.236, v1.283, v1.308)
- **Media time and seeking.** Media-time boundary triggers survive a stale pointer and sparse iOS timeupdate: a both-ends band plus a CROSSING catch within a max step. Live transcode: every duration/currentTime consumer and seek writer branches on liveMode (grep `seekTotalDuration`, `currentTime=`, `fastSeek`, MediaSession `seekto`). A continuous playback gesture REUSES the seek pipeline and is TIME-based (commit via `#seek-bar` 'change' on pointerup, pointercancel aborts). A wrap/loop never masks TRUNCATION: gate on raw `items.length` vs `total`. Playback UI timers: reset a classifier's companion stamp on every exit inside one setter; auto-hide treats a DRAG as activity (`!isScrubbing`); no `pointer-events:none` on a captured element mid-drag. (v1.41.11, v1.41.12, v1.118, v1.119, v1.139, v1.239, v1.240, v1.243, v1.279)
- **Fullscreen has TWO mechanisms** (faux CSS on mobile/iOS, native + `#fs-stage` on desktop): gate on `.css-fullscreen` AND `:fullscreen`; iPhone `webkitEnterFullscreen` sets neither; entering mid-play fires no `play`; iOS PAUSES on programmatic native exit. (v1.118-v1.141)
- **Media facts and reuse.** native `<track>` captions obey WebVTT cue SETTINGS, not `::cue` (normalize server-side); release a mobile decoder with `removeAttribute('src'); load()`; detach a prior begin's listeners via a WeakMap. Extend a feature through its PROVEN contract (chapters reused `::c`; the launch cover reused `renderFull`), keeping the builder pure and exported, its try/catch net bound. (v1.41, v1.94, v1.280, v1.301)

## 6. CSS, layout and stacking

- **Specificity and selectors.** An ID outranks any number of classes, and inline style outranks every class: a scoped override carries the same ID count + a class, fixed at the base; adding `#id .x` re-checks class-only context rules; an inline->class move audits specificity and `.style`/className readers. A selector matching nothing is a silent no-op and a class with no rule is a defect; an unscoped member of a scoped group applies everywhere (lock the scope on every member). Buttons do NOT inherit the body font: a new button/menu family sets `font-family` or `font:inherit`. (v1.38, v1.68.3, v1.77, v1.163.3, v1.255)
- **Deleting and decorating.** Prefer DELETING an interceptor to out-clevering it; fix the causing property once; a deletion ships an ABSENCE lock plus locks on its load-bearing partners. Never wrap a flex-`order`ed child to decorate it (`order:` beats DOM order): decorate via an absolute `pointer-events:none` overlay; enumerate everything a positioning rule placed before deleting it. (v1.75, v1.109, v1.166.1, v1.169, v1.264)
- **Size overlays and rows against what they live in:** anchor in a wrapper sized to the TARGET; `aspect-ratio` gives `%` children height only on a flex/grid item; a JS `.style.height` kills the CSS rule (MEASURE `offsetHeight`); a control in a fixed `overflow:hidden` bar re-clips its neighbour; derive overlay size from the covered rect. (v1.38-v1.95, v1.261)
- **`overflow-x:hidden|auto` coerces `overflow-y` to auto,** making a scroll container that clips abspos menus (z-index never escapes). Guard: `overflow-x:clip` near the offender, a `:has(#menu:not([hidden])){overflow:visible}` escape; iOS honours root `overflow-x:clip` weakly. (v1.150, v1.194.3)
- **A menu's rows must lie in reachable space:** a clipped popup's scroll cannot reach content above the clip line, and a menu anchored to a trigger's BOTTOM and capped by `vh` puts its TOP above the screen when the trigger grows (unreachable rows read as "can't scroll"). Guard: cap `max-height` by the space actually available (ABOVE the trigger), re-clamped on open/rebuild/resize; measure the top edge against the top safe-area inset for EVERY trigger size (`scripts/skin-chips-probe.js`, `Emulation.setSafeAreaInsetsOverride`). (v1.43.1, v1.333)
- **Layout traps.** Flex/grid min-content traps: a flex item's `min-width:auto` lets a scroller widen its ancestor; grid auto-fit in an indefinite width computes one repetition; `min-height:0` on a flex image/scroll cell is load-bearing (locked). Structural side effects: a bar going `position:static` leaves a phantom reserved band; a zero-padding bleed makes every sibling re-pad (lock each); move a clip EDGE rather than remove a clip. A layout claim is a MEASUREMENT of every state (resting AND armed/expanded) against the real cascade, checking the property really driving size (`aspect-ratio:auto`). Flush-sticky recipe: `margin-top:-pad; padding-top:pad`; exact scroll-restore under an opaque bar is inherent. (v1.38, v1.45, v1.55, v1.190, v1.204, v1.263, v1.300, v1.310)
- **Tokens and skins.** A new token is a THREE-place ceremony (`:root` + the token-scale-lock count + the design-token-audit doc) and passing `lint:css` is not enough; a value that merely equals a token is not adopted; prefer a `data-` attribute where class-string locks exist. Shared components are not a shared contract: authority + registry + a census of every (type x capability) cell (`lib/media-capabilities.js`, `media-capability-census.test.js`) with an orphan check. - **State hygiene:** a write-only field is read or deleted; never blanket-catch module-scope errors; read a helper's return SHAPE before consuming it. (v1.44, v1.48, v1.64, v1.69)

## 13. Git, CI and release

- **Commit mechanics.** No backticks or apostrophes in a shell `-m` body (use `git commit -F -`); `git merge -F -` does not read stdin (use a file, check `git log -1` before tagging). A test that shells out to git inside a hook scrubs GIT_* from its own env (a `git init` flipped core.bare). Long pushes: a push whose pre-push suite runs 7+ minutes dies with exit 141 after "checks passed"; use `GIT_SSH_COMMAND="ssh -o ServerAliveInterval=20 -o ServerAliveCountMax=60"`; two SEPARATE pushes (`git push A && git push <tag>`) run the pre-push suite twice, so push the branch and the tag in ONE command. (v1.311.2, v1.317, v1.319.0)
- **main is protected:** push the release branch at the tagged merge, `gh pr create`, CI green, `gh pr merge --merge`, `git pull --ff-only`. Before tagging grep `^### v<new>` in ROADMAP.md (Shipped silently stopped for four releases).
- **Edits, ignores and lint.** PHANTOM EDIT: a scripted edit can fail silently (a swallowed heredoc anchor, a delimiter mismatch, `sed` turning `\(` into a group): &&-chain, then grep the artifact and re-run each regex assertion. Root-anchor ignore patterns: `media/` swallowed `lib/media/`; check a new file with `git ls-files`, and dirty-tree lock sweeps use `git ls-files --cached --others --exclude-standard`. `eslint-disable-next-line` covers one line; a lockfile bump needs `npm ci` before crediting green. (v1.112, v1.115, v1.206, v1.265, v1.286-v1.292)
- **Guard hooks never match their own documentation:** match at COMMAND POSITION, strip heredoc bodies (quote-aware, excluding `<<<`), and a Claude Code PreToolUse hook blocks only on exit 2. (cleanup-norms hook)
- **Parallel work.** A cross-branch seam is wired by the branch merging SECOND; merge main before a branch's last gate round; a local tag trips sibling worktrees' release-ledger tests. Worktrees: eslint must ignore `.claude/worktrees/`; release-qualify in the MAIN checkout (worktrees skip 3 playwright tests, so seat counts can honestly differ); retire `worktree-agent-*` branches; stale tracking refs need `git fetch --prune`. Dual-Node verification is sequential on an IDLE box (concurrent Node 22 + 24 is the load-flake recipe, #107); keep CI's floating Node minor in the local pair; Node 22 is production. (v1.77, v1.295-v1.299, 2026-09-24)
- **CI and images.** Checkout shape is per JOB (skip history tests on any shallow clone); ask of every new gate "does it run on the TAG push?"; mirror secret-scan/audit into docker-publish; dry-run dispatch after a publish edit; space rapid pushes (one pending run per concurrency group; a fresh tag supersedes a wedged one). Unexecutable config (YAML, CLI seams) needs BODY + ORDER locks and spawn-level tests (PATH-shimmed fake binaries); build once, smoke that image, promote by identity. What prod needs must be in the IMAGE's COPY set or a mounted volume: check Dockerfile COPY + root-anchored `.dockerignore`, pair compose binds with server paths, test `COPY scripts/`. Packaging and rollout: bake the cheap universal fallback (espeak-ng), keep heavy engines opt-in with a README note; a disclosed resource risk ships with a probe before mass rollout and a cheap rollback. (v1.38, v1.89, v1.93, v1.113, v1.123-v1.148, v1.148, v1.166.3)
