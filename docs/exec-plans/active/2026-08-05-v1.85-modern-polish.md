## The four items (Dean's WOW-list after the v1.84 device pass)

### #4 — bottom-left card corner missing in Modern mode ✅ DONE (11d03f7)
ROOT CAUSE (data, not CSS — hence modern-only): resolveModernGridItem omitted
`watchUrl`/`ext`, so a corner set to Share (or download-filename) rendered empty
while download/delete (id-only) showed. Fixed: the grid item matches the
/api/videos projection (watchUrl via buildWatchUrl, ext).

### #3a — avatar bar shows no photo for registry-only avatars ✅ DONE (ef3a2bf)
ROOT CAUSE: /api/channels read only the baked item.channelAvatarUrl, not the
channelId registry the Subs menu uses. Now resolves via resolveItemChannelAvatarUrl.
SURFACED A LATENT v1.84 PRODUCTION 500: that resolver called ensureYtdlp(db)
which MUTATES; on the read-only getCachedDatabase() the normalizing write threw
the moment an item with a channelId + no baked avatar reached it (the gate's
fixtures never did). Fixed with readYtdlpNamespace (read-only view) in the two
READ functions. Deferred (Dean's call): the "Fireship" vs "@Fireship" folder-
identity MERGE (group by channelId) — riskier, separate wave.
