## Design decisions (mine to make, disclosed here)

- **One schema bump v9 -> v10** carries everything per-user this wave
  needs: the `user_podcast_liked` table (item 4) and an
  `entry_kind` column on `user_queue` (item 6). Additive-only, new
  `if (current < 10)` block, header-comment ritual continued.
- **Queue entries gain a `kind`** (`'media'` | `'podcast'`, default
  `'media'`). Podcast episode ids are md5 hex just like media ids -
  NOTHING structural distinguishes them (the v1.69 lesson), so the kind
  must be carried, not inferred. Legacy rows read back as media.
- **Off-by-default bottom-bar item**: `resolveBottomNavLayout` gains a
  `DEFAULT_HIDDEN` set (`['podcasts']`) and the config gains a `shown`
  list. Visible = present AND NOT hidden AND (not default-hidden OR
  explicitly shown). Existing configs (no `shown` key) keep today's
  behavior for every current item and hide podcasts - exactly Dean's
  "customizable optional item, off by default".
- **Podcast deep link** is `/podcasts?play=<episodeId>` (mirrors
  music's `?play=`): opens the owning show, scrolls to the row, starts
  docked playback (which always resumes - the v1.69 `resumeMode:
  'podcast'` ladder). Queue rows, queue advance, up-next and the home
  row all point podcast entries there.
- **Episode download rides `GET /episode/:id?download=1`** with the
  shared `contentDispositionAttachment` threaded in via deps (the
  `d.sendRangeable` pattern). The v1.70 confinement checks are UPSTREAM
  of the new branch and untouched. ytdlp-toggled episodes
  (`ep.watchHref`) keep the existing `/video/:id?download=1` path.
- **Expanded now-playing**: `podcasts.html` gets a `#player-slot`;
  `'podcasts'` joins `shouldDockOnTransition`'s FULL-view list; the
  docked player's tap-to-expand already exists - on /podcasts it
  expands in place instead of navigating. The audio presentation
  itself is UNCHANGED (type:'audio' + artUrl already produce the
  cover-art player Dean asked for - "audio only style from ytdlp").

- **T2 - bottom bar.** `'podcasts'` into `BOTTOM_NAV_OPTIONAL` +
