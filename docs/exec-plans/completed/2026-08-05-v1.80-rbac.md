1. **Blocklist fails OPEN** (a missed route or a brand-new top-level root =

2. **Granularity:** restrictions are per-unit - a video ROOT (prefix), a video

   restrict every non-kid root + all podcasts + (optionally) all music/books.
3. **Path scrubbing default:** non-admin JSON strips absolute paths
   (filePath/rootFolder/channelDir/config roots). Admin sees them.

## The model

`user_restrictions(user_id INTEGER, kind TEXT, value TEXT, PRIMARY KEY(user_id,
kind, value))`, kind ∈:
- `path`  - value is a filePath PREFIX; blocks any video/music/book item whose
  `filePath` starts with it (covers a configured root AND everything nested,
  including future downloads).
- `folder`- value is a video `folderName` (a channel); blocks those items.
- `show`  - value is a podcast `subId`; blocks that show's episodes.
- `library` - value ∈ `video|music|podcasts|books`; blocks the whole library.

Admin implicitly has zero effective restrictions. A member's set is read once
per request (cached on `req`), keyed by `req.user.id`.

## THE authorization helper (the single decision point)

`lib/auth/visibility.js` - PURE. `isBlocked(restrictions, descriptor)` where
descriptor = `{ kind:'media'|'track'|'podcast'|'book', filePath, folderName,
rootFolder, subId }`. Returns true if the item is blocked. Admin is handled by
the CALLER passing an empty restriction set (or a short-circuit). Named +
exported; every list filter and every serve route routes through it - NO route
re-implements the check (the v1.41.4 every-writer scar). Heavily unit-tested:
prefix boundaries (`/a/b` must not match `/a/bc`), library toggles, each kind,
prototype-safe value handling.

## The census forcing function (the control)

Extend `test/integration/route-census.test.js` (which already enumerates the
live `app._router.stack` and asserts gated-vs-allowlisted). ADD:
- A CLASSIFICATION map: every route -> `public | user | admin | serve`. The test
  fails if a live route is unclassified (so a NEW route cannot ship unclassified
  - this is what prevents a silent miss).
- For every `serve` route: mint a restricted member session, seed a restricted
  item, hit the route -> assert **404** (not 403 - don't confirm existence), and
  assert an UNrestricted item still 200s for that same user (proves the gate
  discriminates, not just blanket-denies).
- For every `user` list route: assert a restricted member's response contains no
  restricted item and no absolute path.

This test is the release gate: green == every surface covered.

## Per-user subscriptions

`ytdlp.subscriptions` stays the instance channel REGISTRY (downloads unchanged).
`user_follows(user_id, channel_id)` drives each user's Subscriptions view + the
feed's "New from subscriptions" row + `/api/videos?subs=1`. A member's feed subs
row and subs browse read THEIR follows. Registry add/remove gated by admin or
`canManageSubscriptions`. Podcast subs get the parallel `user_podcast_follows`.
(Deferrable to a follow-up commit if time runs short - the visibility model is
the priority; per-user follows are additive and lower-risk.)

## Acceptance criteria (numbered; the census test binds most)

- **AC1** A restricted member gets 404 on every SERVE route for a restricted
  item, 200 for an unrestricted one; admin gets 200 for all.
- **AC2** A restricted member's every LIST/feed/search response omits restricted
  items and their counts.
- **AC3** No non-admin JSON contains an absolute server path.
- **AC4** The route-census classification is COMPLETE (no unclassified live
  route) - a new route fails the suite until classified.
- **AC5** Admin bypasses all restrictions; existing single-user installs (one
  admin, no restrictions) are behavior-unchanged - no migration needed.
- **AC6** Prototype-safe: a restriction value or id of `__proto__` is inert.
- **AC7** `canManageSubscriptions` (or admin) is required to mutate the channel
  registry; a plain member 403s.
- **AC8** Per-user subscription follows drive the feed subs row + `?subs=1` +
  the Subscriptions view (if T10 lands).

## Named attack surfaces (brief the adversarial seat to BREAK the kid account)

- S7 a NEW route added without classification (prove the census test catches it).
