# Lessons

The cross-tool home of FileTube's recurring bug classes and the guard that catches each one. Read it
before writing or reviewing a change, and brief gate seats with the sections the diff touches.
`AGENTS.md` links here and the Claude memory index points here; this file is the live source for bug
classes.

**Maintenance rule.** A shipped wave adds or updates its lesson HERE, in its release commit.
Deduplicate first: if the class already exists, bump its strike count and version list instead of
appending a near-copy. Per-release memory files are never written.

**Entry format.** `- **Rule, stated generally.** Guard: <test / command / check>. (versions; xN)`.
This file holds each section's Classes (crown jewels and anything struck 3 or more times); the
long tail of one-line Rules lives in [`LESSONS-rules.md`](LESSONS-rules.md) under the same section
numbers. Stories stay in git, `ROADMAP.md` and `docs/releases.json`.

## 0. Read this first

- **Presence is not binding:** delete or mutate the guard and watch the test go red (section 2).
- **Inert feature:** prove REACHABILITY by driving the REAL upstream shape, never a hand-typed one (section 2).
- **Inert sibling list:** a new entry does nothing until EVERY hand-maintained list and consumer carries it (sections 12, 3).
- **Lying comment (~45 strikes):** a comment, test title or doc the change inverts is a finding (section 12).
- **Reveal and clear are two axes:** bind the reveal AND every error/abort/close clear, from a POPULATED state (sections 2, 4).
- **Numbers are copied from an instrument (x15):** never typed from memory (section 1).
- **A destructive editor seeds from STORAGE,** never the projection; data-loss work gets the full gate (section 9).
- **The SPA swaps only `#view-root`:** what a view needs must ship on EVERY shell (section 4).
- **Access control is enumerated:** every mutating route, every read/list/count surface, the backup bundle (section 10).
- **Persist-gate:** a new persisted field joins every carrier, merge guard and gap-fill (section 9).
- **Blast radius (x9):** a rule reaches every element it matches, including reparented ones (section 6).
- **A fix that fails on device means the diagnosis was WRONG:** re-root-cause, never re-patch (section 1).

## 1. Gate, diagnosis and honesty

#### Classes

- **Diagnosis discipline: name the FALSIFYING observation before editing; a shipped fix that fails on device means the diagnosis was WRONG, so re-root-cause, never re-patch the theory.** Guard: ship an INSTRUMENT or discriminating probe (or both fixes), not a theory-fix; use the existing one first (`?debugLifecycle=1`) and check the user's settings; "confirmed" only for a discriminating measurement taken ON the device; the user's exact WORDING and any ASYMMETRY are evidence; deterministic vs intermittent discriminates, a reproducing variable can be a bystander, several symptoms can be ONE cause; prove "did my code load" (served bundle hash+length vs HEAD); "unreachable" is a theory to TRACE, and an obvious fix already in the code means the cause is elsewhere; trace the path the DEVICE takes; check the observation is a malfunction at all (the boops were IN the MP3s); never falsify on a WebKit-only property, read the model's type field; hand-computed pixels are a guess, revert to the pattern proven on the user's hardware; an instrument is verified where the user READS it (v1.336: the log panel cut every new line at 60 chars and its tap-to-clear sat over the fullscreen play button, while the probe read the store) and its counters are read at primary source for the device's engine (iOS relays the video layer's frame count from the GPU process as a ~2s cached copy: sample a series, never one reading). (v1.38.2-.4, v1.157.1, v1.179.1, v1.244a, v1.336; x7+)
- **Diagnose the MODEL FIELD and the SURFACE, not the render; a "never show X" ask wants a NET, not a spot-fix.** Guard: find the field and the RENDERER the user actually sees (three home renderers existed); every projection feeding a renderer carries the field; key layout shifts on the RENDER outcome (`brOccupied`), not the pref; derive a missing field at the shared choke point (`ensureChannelAvatar`); broken-image net = self-nulling onerror (`this.onerror=null` before `this.src=`); check caches an older version wrote (`comments_<id>`); point fixes to a systemic gap re-bite. (v1.203, v1.204, v1.288, v1.302; x5)
- **Verify what a prescription REMOVES and ADDS, not just what it claims.** Guard: re-run the OLD lock's mutants against a rewritten lock, in every form it caught (`+=`/`||=`, `Object.assign(el.style)`, alias, non-literal `setProperty`); re-derive termination and load (a retry fix became a 1 Hz 403 flood); check the implementation (`length < undefined === false`); cross-check seats' prescriptions against each other and their round 1; confine a prescribed clear to skeleton nodes (`[aria-hidden="true"]`); a better-tested stated deviation is the system working. (v1.33, v1.77, v1.82; x6)
- **Every number in a commit, delta, ROADMAP entry or brief is COPIED from a standalone instrument run on the staged tree.** Guard: measure and commit in separate commands; quote the runner's final summary line with its command; never inherit a magnitude; census-bind hand-typed counts; report failing test NAMES with counts, keep full logs (a count-only grep lost a flake; a `tail` cut reporter lines). (v1.131-v1.203, v1.290-v1.298, design tokens; x15+)
- **Claims vs tree: never report an edit applied, or a class "fixed/swept", until an independent read of the WHOLE tree shows it.** Guard: scripted edits assert match AND effect (a `str.replace` silently no-opped); re-read after fuzzy edits and `git diff` before commit; grep the added/removed text repo-wide, not the remembered line; resolve paths wrapped across comment lines; read the whole block, not a grep window; never interleave mutant apply/restore with uncommitted fixes. (v1.48, v1.73-v1.77, v1.133, v1.135, v1.137, v1.166, v1.187.2; x6+)
- **Fix rounds introduce the next defect; every fix round is re-reviewed.** Guard: delta re-confirm with the SAME seat; mutate every fix you just wrote; audit the callers of anything a fix changes. (v1.26.3-v1.69, v1.304, v1.316; x8)
- **Gate seats never share a mutable tree, and nobody edits a tree a seat or subagent may still touch.** Guard: mutating seats get `isolation: "worktree"` (mutants in a /tmp `git archive` sandbox) or run sequentially; wait for every agent to commit or be killed before editing overlapping files; re-check branch == HEAD after a worktree is removed. (v1.79-v1.86, v1.127-v1.140, v1.249, v1.285, v1.300; x6)
- **Seats SPLIT: one can APPROVE while the other holds a CRITICAL.** Guard: never collapse to one seat for UI/layout, persistent-shell or data-carrier changes; the device probe arbitrates layout. (v1.95-v1.160; x5)
- **A dead session leaves gate state behind** (an unreviewed commit on main; finished agents cannot resume). Guard: re-dispatch pending reviews after a restart; SendMessage a still-live subagent, else a FRESH seat with plan + prior findings + "verify each r1 finding against the fix sha"; git forensics before blaming an agent; re-verify a seat's tools after an agent-definition edit, never kill a mid-gate reviewer over one. (v1.42, v1.127, v1.128; x3)
- **Measure the REAL data before designing on it or dismissing an edge case.** Guard: confirm fields exist at intake; pull the live distribution; if the dev box cannot profile, ship a read-only in-image sizer for Dean's prod, THEN scope. (v1.79-v1.219; x4)
- **The agent writes invisible raw NUL/control bytes when reasoning about control characters, and grep then goes silent (binary).** Guard: build control chars programmatically (Edit/Write decode `\u0000` to a raw NUL; placeholder then `perl -pi`); if an Edit fails to match or grep goes quiet, `grep -aPn '\x00'` / `cat -A` FIRST; scan `git ls-files -z | xargs -0 grep -lP '\x00'`; the raw-byte lock proves each root reds; `git checkout <untracked>` restores nothing. (v1.37.5-v1.44.2, v1.171, v1.217, v1.291-v1.296; x10)

## 2. Test binding: can the test actually fail?

#### Classes

- **Presence is not binding: a test that claims to bind a guard must go red when the guard is deleted or mutated.** Guard: EXECUTE the real handler (jsdom, vm, stubbed `self`), hoisting decisions into exported top-level fns ("decision vs use"); confirm the mutant dies BY NAME; a source lock passes on code that CRASHES (TDZ) and on a listener never bound; bind the ENABLING WIRE (lookup, toggle, mount param, wrapper call) and every link of a paint/data chain; bind BOTH axes of a symmetric invariant (a filter in Next but not Prev); to bind one guard of several make every OTHER condition pass, and give a conjunct `A && B` a fixture varying ONLY B (each fix-round conjunct its own kill test); seed and mutate each of N kinds separately with EXACT counts, binding every factor; lock by the early-return literal; a dedup guard needs length + Set-uniqueness; re-examine "equivalent mutant" verdicts, and a survivor on correct code is still a WARNING; a PROMOTED affordance gets a behavioural binding; settings bind persist AND reflect-on-load; validators run per mime with real/lying/empty bytes; a flag default is PROVEN off by a sweep; run the REVIEWER's mutants too. (v1.44, v1.63, v1.83, v1.132, v1.134, v1.192, v1.254; x10+)
- **INERT FEATURE: a green unit test of code that never RUNS in production is worthless; prove REACHABILITY with the REAL upstream shape, never a hand-typed one.** Guard: drive the SERVER-EMITTED shape (`{sound:null, voice}`) through the real planner, and fixtures from real dumps (`GET /api/liked`, real `formatDiskBytes` output, the hidden-bar rect the `?tv=` path really measures); brief the gate for reachability, not unit correctness; test a new entry path END-TO-END (search -> `?play=` -> re-resolve); run the real `init()` TWICE on one module instance; thread a new per-item field through the whole pipeline, with a client-seam tripwire when server tests inject at the store; a new media type reuses the player's ERROR/RETRY branch; a mouse `click` guard is dead on touch; a field committed only at the END of a pass prod never finishes is dead (prefer per-item, disk-keyed convergence); model the failure's MECHANISM (a 40000px spacer + an anti-vacuity pre-flip assert for lazy images); scaling a knob without its cap is the same class. (v1.184, v1.185, v1.271, v1.306, v1.321 desktop theatre; x8)
- **Divergent-fixture tests stay green through broken code: pick inputs where correct and broken output DIVERGE.** Guard: survivors at a divergent spelling (full-width `？`, emoji ZWJ, invalid UTF-8, a proxy host for a youtubeId guard); VERBATIM third-party output (real yt-dlp stderr) through the real spawn boundary, with a negative control; fixtures in the PERSISTED shape; a pixel where #0f0f0f and black differ; bind each arm of an OR match; one fixture per ARGUMENT AXIS (`needsTranscode(ext, codec)`); geometry at the origin/edge where clamps engage; ids whose lexical order OPPOSES the sort key, and a sort where file and list order diverge; fake routes return DIFFERING values; race stubs snapshot per request; a "force" flag beats EVERY guard; jsdom pointer events are a plain Event with `pointerId` (or jsdom 29.1.1's PointerEvent), never MouseEvent; the harness VIEW_HTML mirrors every element the code reaches, `player.load` stubs EXPAND, planner loops assert length > 0; a changed DEFAULT ripples into every test; a sweep gets a STRUCTURAL post-check, never a re-run of its own regex. (v1.41.9, v1.41.13, v1.47.4, v1.67, v1.77, v1.133, v1.258, v1.271, v1.331; x8)
- **Reveal-once has TWO axes (the REVEAL and the error/abort/close CLEAR), and a CLEAR test on an element BORN empty or hidden is VACUOUS.** Guard: populate FIRST, then drive the non-showing axis; for every floor ask "does the driver REACH the state the assert is about" (read a probe fixture's theme/viewport BACK; read the TABLE back before asserting seeded rows); a test that sets ALL prefs binds only an early return; a census needs a SCAN-level control with a WITNESS per file class; a new gate re-checks that every earlier "never X" still reaches X. (v1.96-v1.105, v1.130, v1.272, v1.316; x7)
- **The pre-commit/pre-push UNIT hook hides a RED integration suite.** Guard: full `npm test` before the gate and after any route, markup, DOM-id, user-creation or settings-seed change; read `echo $?` unpiped. (v1.79, v1.92; x3)
- **To bind one guard, build the input ONLY that guard refuses; redundant guards MUTUALLY MASK.** Guard: an isolating test per guard that disables the other paths; derive the survivor geometry analytically; an override fixture WITHOUT the `source` flag; document a truly masked mutant as masked, never fake-test it. (v1.48, v1.53, v1.176, v1.178, v1.210; x5)
- **One parameterised template is not N bindings: bind every case, surface and input modality separately.** Guard: one exact test per orientation/edge/notch topology (unreachable arms too), naming which test kills which mutant; mobile skin AND desktop panel; click-blocking claims tested by pointer AND keyboard (Tab + Enter behind a backdrop). (v1.168-v1.177, v1.253; x4)
- **A race test's precondition is EVENT-LOOP ORDER, not timing.** Guard: enqueue the racing call in the SAME synchronous turn; hold the handler open (deferred) so the race happens; deps spread at registration need a STABLE hook delegating to a swappable impl; promise/setImmediate interleaving is deterministic, so timing-flake objections do not transfer. (v1.48, v1.70, v1.273; x4)
- **A twice-failing "flake" is probably not a flake, and your change can red an UNRELATED test.** Guard: run the FULL suite after a new invariant; on a second identical failure read the test before re-running; run it standalone AND on clean main; a diff-independent flake is proven when an unrelated added file reproduces it (`npm test` is ONE pool, #212); drain `scanState` in beforeEach after fire-and-forget routes; drain load first (`until awk '{exit !($1<2.5)}' /proc/loadavg`); the real fix is fake timers or awaiting the frame, and a flake is root-caused the day its revisit trigger fires. (v1.192, v1.278, v1.298, #53, #194, #238; x5)

## 3. Locks, censuses and instruments

#### Classes

- **Comment-porous source locks: a lock satisfied by a COMMENT, a lookalike or a distance window binds nothing.** Guard: strip comments ONCE at read, SYMMETRICALLY (must-match locks too, CSS and JS: block, line and trailing), mindful that a `/*` inside a line comment opens a pseudo-block (#228); parse rules into (selector, body) with an EXACT selector, brace-walked (fails closed), `@media` flattened; anchor on the SEMANTIC unit, never widen a distance window; a MARKER is feature-specific on a UNIQUE token (gut the real control per marker and watch the census red); temper spans to one function (`(?:(?!\n {4}(?:async )?function )[\s\S])*?`), keyed so it fails LOUD; never substring-match a pinned number (`0.2` in `0.25`) or rely on `.includes()` (an OUTER twin satisfies it); assert the audited region is UNIQUE and mutate the census's blind spots (respelling, comment shadow, relocation, duplication); a negative lock strips the one sanctioned spelling then asserts zero; order locks are beaten by a shadowing local, so bind behaviourally too; update locks in lockstep with the refactor, never write `--token-name:` or needles in prose. (v1.50, v1.77, v1.133, v1.286, v1.303, v1.304; x8)
- **A CSS/JS CONSTRAINT lock covers vendor spellings, case and sibling properties.** Guard: `-webkit-filter`, `FILTER:`, `style.webkitFilter`, `scale`/`translate`, `@keyframes` + `animation`, a gradient on a SIBLING rule; a word-start guard (`attributeFilter:` false-trips); read WebKit CSSProperties.json for aliases; property-boundary regexes (`border: none` contains `order:`); first-match extractors need exactly-one-rule counts; ban `Date.now(` alongside `performance.now`; the same net covers command spellings in CI blocklists (`gh pr merge --auto`). (v1.77, v1.313; x4)
- **A forcing/completeness net is a DENYLIST that fails by default; its exemption list is an allowlist.** Guard: bucket every live item with a partition assertion and no default bucket; every exemption carries a checked justification (`na('why')` >= 15 chars) read from what the handler writes (a `:mediaId` exclusion hid a file relocate). (v1.123, v1.127; x3)
- **Census tests a route or setting add must trip** (a green suite after an add is the tell): `rbac-census` EXPECTED_ROUTE_COUNT (a new content route also needs a visibility check); `route-read-classification` (every GET classified); `route-write-classification` CLASSIFICATION + VISIBILITY (both maps, same set; 'admin' triggers a member-403 probe, so `requireAdmin` goes FIRST); `docs-diagrams-census` (count of top-level `app.<verb>()` in server.js); `setup-automation-reveal` SETTINGS_FED; `shell-script-global-collisions` (a standalone page is EXCLUDED); `css-token-lint` (`// token-exempt:` must be a LINE comment in JS). (v1.259, v1.307; x3)
- **Code PLACEMENT is load-bearing for locks.** Guard: modifiers AFTER base rules; mobile overrides in the MAIN mobile block; one rule per line; no braces, apostrophes or forbidden substrings in scanned comments; exactly ONE base rule; words in spans when adding icons. (v1.45-v1.56, v1.187; x5)
- **An old lock going red on your change is a FINDING;** an outgrown lock is updated with intent preserved, never widened. Guard: comment the reason with the gate round; filter only intentionally moved ids against a compat oracle; when a backfill breaks a gate, fix the FIXTURE and re-mutate; comply rather than widen (v1.334: ipod-brick's engine-never-draws lock moved the sticker painter out of the engine; the pocket structure-token census turned raw sizes into tokens; v1.335: token-scale-lock and AC5 went red when a new LOOK re-pointed contract palette tokens and redefined the type sizes - the compliant move was a ROLE layer the look re-points (`--pk-s-*`, each exactly its token on the chassis) and `font-size-adjust`, never a second value for a contract token). (v1.52-v1.92, v1.334, v1.335; x7)
- **Design-token census ceiling is ZERO** (`npm run lint:css`): new literals in governed properties are tokenized or `token-exempt`-annotated. Governed (scripts/css-token-lint.js): color, font, font-size/weight, line-height, letter-spacing, box/text-shadow, transition/animation, border-radius, padding, margin, gap, top/right/bottom/left/inset, z-index, JS `.style.X = literal`; not governed: width/height/min/max, font-family, @font-face, HTML-string styles, custom-prop values. Guard: every font-size is EXACTLY `var(--fs-*)`; gradients/shadows pass only with all-var() stops; `token-exempt` exempts the WHOLE line (#200) and must be a LINE comment in JS; negative margins need `token-exempt: positional`; the census is blind to `[data-theme]`-scoped rules (#103), so era sections carry their own tokens-only lock; token-scale-lock's DEF regex is not comment-stripped; bespoke palettes need the contract doc + `:root` + a byte-exact scale lock.
- **Overlay containment census ceiling is ZERO** (`node scripts/overlay-containment-lint.js --enforce`). Guard: a rounded overlay that scrolls SPLITS clip (outer `overflow:hidden` + radius) from scroll (inner `overflow:auto`, no radius), since combining them is the iOS corner-clip-escape shape; exempt a proven surface with `/* corner-clip-safe: <reason> */`; after three per-instance fixes, build the family census. Full rule: `docs/CONTRIBUTING.md`.
- **A probe must be able to show a DIFFERENCE, and a render probe's identity is proven, not assumed.** Guard: the BEFORE run must differ or the AFTER match proves nothing; classify EVERY element-style difference by script into the intended subtrees; compare pixel diffs against two runs of ONE tree; a neutral pose cannot see a sign flip or missing layer (count layers vs sizes/positions); one probe at a time on a quiet box. (v1.316, v1.327, v1.332, v1.333; x4)
- **Wait for CONVERGENCE, not a fixed count or a readiness event.** Guard: converge on a stable identity set (2 observations, zero in flight, budget-bounded, report `stable:false`); chain late fixtures causally; an errored image is `complete` with naturalWidth 0; `document.fonts.ready` before use is vacuous, force-load every face. (design tokens; x4)

## 4. SPA shell, client lifecycle and async UI state

#### Classes

- **SHELL PARITY: a global script a soft-nav'd view depends on ships on EVERY shell that can host it,** because the SPA lazy-loads view js into whatever page was cold-loaded. Guard: a DYNAMIC parity test enumerating `public/*.html` each run plus module-served shells (`lib/ytdlp/views/subscriptions.html`), with fail-safe floors on shells-found and shells-checked, never a hardcoded list; a per-shell STRUCTURAL pre-paint lock (`pre-paint-fouc-guard.test.js`) and cross-shell byte-equality for shared blocks; a player-HOSTING shell carries `#player-dock` + `#player-host-template`; respect adjacency locks (music-skins.js before skin-surface.js); prefer injecting from the one choke point (`sendShellHtml`). (v1.230, v1.250 QA CRITICAL; x3)
- **The SPA swaps only `#view-root`; "works on refresh, not in-app nav" is the tell.** Guard: view-owned DOM (the player mount slot too) lives INSIDE `#view-root`, shell-owned (`#player-dock`, `#player-host-template`) outside, and no `#view-root` ancestor has transform/filter/perspective; a new modal ships markup + its `[hidden]` companion in the view and styles in style.css, never page-local `<head>` styles; route-bind persistent-header controls via `body[data-view]`; home is CACHED on nav-away and restored WITHOUT init or abort, so gate its side-effecting listeners on a view-child `isConnected` and let late results ask the SURFACE (`stillWanted: () => btn.isConnected`); a view's body class is cleared in destroy() AND its CSS scoped to `#view-root[data-view=...]`; a non-route destination full-reloads and kills the player; a same-route nav IGNORES the hash (pathname+search only), so set `location.hash` directly and bind cross-page AND same-page deep links. (v1.38, v1.44.2, v1.86, v1.160, v1.305; x6)
- **A pre-await guard is NOT a post-await guard (TOCTOU).** Guard: gate on the REAL precondition and RE-CHECK after every await; an async-registered GLOBAL handler checks `signal.aborted` before registering; long jobs re-validate their target before finalize (purge racing restore freed a file's last link); generation counters; a wrong-item race has TWO axes, the loser's PLAY and its SHARED WRITE (guard inside the shared loader); one open funnel re-gates EVERY pre-await axis (view alive AND viewport), a pending flag covers double-click, a same-queue switch re-checks identity; never render during a pending save burst or a focused field; bind with a manually resolved promise (toggle OFF mid-flight, assert nothing rendered). (v1.104, v1.105, v1.273; x5)
- **Reveal-once, UI half: every reveal PATH and every seed site gets its own paired CLEAR.** Guard: grep all seed sites (play vs reseed); reconcile state preserved through teardown with one both-axes call `setX(!!cond)`; `.hidden` and `style.display` are independent, bind both; a render depending on TWO async inputs reveals only when both settle (flags released on success AND error), and a new late input joins the barrier; pick representatives order-invariantly and never let an empty string win; jsdom's emptied path needs `#media-player` + a rAF global. (v1.96-v1.105; x6)
- **A per-move `preventDefault` handler RE-EVALUATES direction every move, and a stashed global/CAPTURE listener UNBINDS on EVERY teardown arm.** Guard: bind unbind-BALANCE across every arm, incl. a strand-recovery rebuild (test: strand -> reopen -> close -> post-close ArrowDown NOT prevented); claim and fire share ONE dominance constant; the no-shake belt is CSS (`html{overflow-x:clip; overscroll-behavior-x:none}`), since a lazy iOS preventDefault may be non-cancelable; the passive tracker registers first; skip drags inside horizontal scrollers; modifiers pass through; an IntersectionObserver is NOT covered by the view's AbortController. (v1.160.3, v1.163, v1.271; x3)
- **A GLOBAL non-passive touch listener is a scroll-perf regression:** passivity is fixed at REGISTRATION, so a document `{passive:false}` touchmove slows every scroll even when it early-returns. Guard: attach on the gesture's start event; the state-nuller is the SOLE remover. (v1.160.1)
- **Down listeners on both pointerdown and touchstart must be idempotent; prefer ONE down event.** Guard: one registration + a pure stamp fn (<150ms same-gesture stamp), the double-fire sequence as a pure test. (v1.134)
- **A `position:fixed` BODY LOCK changes what scroll means** (pinned = `scrollY` 0 + a clamped `scrollTo`). Guard: route EVERY scroll reader/writer through `FileTubeBodyLock`, fixtures clamp too, lifted wiring gets a CALL-SITE binding; iOS Safari does NOT lock with `overflow:hidden`; a MEDIA-QUERY-gated cover re-evaluates on the crossing (a rotate once un-covered `.mms-full` with the lock held); jsdom hides the microtask checkpoint BETWEEN listeners. (v1.311.2, v1.311.3)
- **Every handle KIND (listener, IntersectionObserver, MutationObserver, debounce/settle/retry/deferred-start timer) is cancelled at EVERY boundary it crosses (nav, re-render, mode-off).** Guard: list live handles per boundary; track an `observed` Set and unobserve `!isConnected`; prune active AND pending maps; module-global observers are per-document (a later test gets the blame). (v1.92, v1.93.3, v1.167-v1.182 QA CRITICAL; x5)
- **A component that REBUILDS rows resets per-row transient state: a two-tap destructive arm must never survive a re-sort into a one-tap delete.** Guard: render-local arm state or an `onRender` disarm; row actions close over the DATA id, never an index; the test taps the SAME armed item after the sort; numeric columns sort by RAW value; per-view sub-state lives on the container class the render rewrites. (v1.159-v1.231; x3)
- **Never ship a control with no observable result, and never silently no-op a refusal.** Guard: hide the affordance when its input/handler is absent, binding both axes; prefer a visible toast to a silent return. (v1.41.12, v1.198; x3)

## 6. CSS, layout and stacking

#### Classes

- **A rule's blast radius is every element it matches:** a shared class, a global `#id` rule on an element JS reparents (dock, fullscreen), a "dead" hide rule, or a rule family an element JOINS (mobile `.btn{min-height:44px}`).
