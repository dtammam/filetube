# Icon sources (the registry's inputs)

Material Symbols, © Google, **Apache License 2.0**
(https://www.apache.org/licenses/LICENSE-2.0), fetched unmodified by
`tools/icons/fetch.js` from https://github.com/google/material-design-icons at the
commit pinned there. `outlined/` and `rounded/` are the Outlined and Rounded families at
FILL=0; `filled/` is the Outlined family at FILL=1; `<name>.fill.svg` is a name's FILL=1
twin in that set (on-states). `tools/icons/build.js` compiles them into
`public/js/icons.js`; these files are not served.
